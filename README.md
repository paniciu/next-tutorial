# SkillForge

SkillForge is a personal AI copilot for skills and career growth.

This repository is being built step by step as a course project focused on connecting a real web application to an LLM-powered agent.

## Current status

- Documentation foundation is in place.
- Product requirements live in docs/requirements.md.
- Application code will be added incrementally in the next steps.
